# ADR 0010：项目计划与治理层

## 背景

`project-progress.yaml` 只适合记录固定交付流水线，`desired-tasks.json` 只适合表达待同步的任务意图。复杂项目还需要阶段依赖、并行工作线、团队容量、风险、问题、变更和决策登记。

## 决策

- 新增 `project-plan.json` 作为项目计划层，负责人和日期可选，团队人数可记录。
- 新增 `project-governance.json` 作为风险、问题、变更和决策的统一登记。
- 飞书仍是执行状态唯一真源；计划层和治理层不保存飞书状态。
- 计划和治理文件为可选兼容能力；启用后由 `delivery-check` 纳入门禁。
- 不复制 BMAD、Superpowers、`lark-*` 或通用文档生成器的实现。

## 门禁规则

启用治理登记后，未关闭的 P0 风险、阻塞问题和待审批范围变更会阻断项目检查。阶段级验收由 `delivery-phase-gate` 按计划阶段独立执行。
